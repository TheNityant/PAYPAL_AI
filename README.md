# PAYPAL_AI — IntentParity

This repository hosts **IntentParity**, an experimental AI payment-intent evaluation and PayPal **Sandbox-only** checkout prototype.

The implementation is developed on a feature branch and reviewed through pull requests. **Do not use it for real-money transactions or publicly expose it without additional authentication, persistence, access controls, and security review.**

The project's originality and effectiveness remain research hypotheses; automated authored-fixture tests do not establish real-world performance.
